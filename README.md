# CodeAlpha – Credit Scoring Model

This project is a **Machine Learning-based Credit Scoring Model** developed as part of the **CodeAlpha Internship**. The model predicts whether a customer is likely to **default on a loan** based on their financial information and credit-related attributes.

## Features

* Data preprocessing and feature selection
* Handling categorical and numerical data
* Exploratory Data Analysis (EDA)
* Model training and evaluation
* Comparison of multiple machine learning algorithms:

  * Logistic Regression
  * Support Vector Machine (SVM)
  * Random Forest
  * XGBoost
* Performance evaluation using:

  * Accuracy Score
  * Confusion Matrix
  * Classification Report
  * ROC-AUC Score
  * ROC Curve

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* XGBoost

## Dataset

The dataset contains customer financial information such as income, savings, debt, credit score, and other financial indicators used to predict the **DEFAULT** status.

## Objective

The objective of this project is to build a reliable credit scoring system that helps financial institutions assess customer credit risk and support informed lending decisions.

## Results

Multiple machine learning models were trained and compared to identify the most effective model based on classification metrics and ROC-AUC performance.

This project demonstrates the complete machine learning workflow, including data preprocessing, model development, evaluation, and model saving for future deployment.
